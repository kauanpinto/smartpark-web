# SmartPark Web

Interface web responsiva para reserva de vagas de estacionamento, integrada com a API do SmartPark.

## Projetos relacionados

[SmartPark API](https://github.com/kauanpinto/smartpark-api.git)
[SmartPark IoT](https://github.com/kauanpinto/smartpark-iot.git)

## Tecnologias

- [HTML5](https://developer.mozilla.org/docs/Web/HTML)
- [CSS3](https://developer.mozilla.org/docs/Web/CSS)
- [JavaScript](https://developer.mozilla.org/docs/Web/JavaScript)
- [Leaflet](https://leafletjs.com/reference.html)
- [Firebase Auth](https://firebase.google.com/docs/auth)

## Deploy

O projeto está hospedado na [Netlify](https://docs.netlify.com)

[SmartPark Web](https://smartpark-web.netlify.app)

## Requisitos

- [API](https://github.com/kauanpinto/smartpark-api.git) rodando em produção ou localmente

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/kauanpinto/smartpark-web.git
cd smartpark-web
```

2. Substitua o arquivo `js/config.js` com suas variáveis do seu projeto

3. Execute o projeto:

```text
Abra o index.html no navegador
```
